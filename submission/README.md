# FitOrder 2.0 submission exports

This directory contains:

- `FitOrder-2.0-Captioned.mp4` — final 86.50-second H.264/AAC submission cut
- `FitOrder-Captions.srt` — burned-in muted-viewer captions
- `FitOrder-Voiceover.txt` — voiceover source

> **AI narration disclosure:** The voiceover was generated by AI from the
> included human-written script. Pronunciation and spoken accuracy may vary.
> The burned-in captions and on-screen seeded demo data are authoritative.

The app and demo server contain only seeded data. No real orders are placed.

The published video is 1320 × 2868 portrait at 30 fps and includes a dedicated
plum caption band so the product controls remain unobscured.

The local workspace may also contain a clean uncut take, raw Simulator capture,
and generated AIFF narration. Those production artifacts are intentionally
excluded from normal Git history.
